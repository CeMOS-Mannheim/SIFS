SIFS Workflow 2: From imzML to Spatially Informed Feature Selection

Shad Arif Mohammed

2026-11-05

Overview

This vignette starts from an imzML file and walks through the complete SIFS workflow:

  1. Load and process the imzML file with sifs_imzML_proc().
  2. Select the matching sample from the label table and prepare the binary response.
  3. Train an XGBoost classifier.
  4. Compute SHAP values for the VT (viable tumor) class.
  5. Compute binary HMCS values with the SPP/MPM/DSC spatial workflow.
  6. Rank and visualize the m/z features.

The workflow uses a single label column, Vt_vs_all_lbls:

  • Vt_vs_all_lbls == "0": VT / tumor.
  • Vt_vs_all_lbls == "1": non-tumor.

No necrosis labels or other label columns are used in this vignette. For XGBoost and SHAP, the response is recoded so that 1 = tumor and 0 = non-tumor.

The binary HMCS comparison is therefore:

HMCS_VT = DSC(MPM hotspot, VT) - DSC(MPM hotspot, non-VT)

The non-VT reference is the complement of the VT mask. This is the Option A workflow: it avoids reading necrosis labels while preserving a binary VT-versus-reference HMCS contrast.

1. Load and process the imzML file

sifs_imzML_proc() performs the imzML-specific work in one place:

  • reads the spectra,
  • bins peaks using the supplied FWHM object,
  • removes low-frequency peaks,
  • creates the sparseIntensityMatrix,
  • selects the requested sample from the labels, and
  • aligns label rows to the sparse matrix rows.

The FWHM-derived binning tolerance is

FWHM at FWHM_setUp / FWHM_setUp

With FWHM_setUp = 400, this focuses the binning on the lipid region. The resulting tolerance is recorded in obj$meta$fwhm_tolerance.

obj <- sifs_imzML_proc(
  imzML_path = imzml_file,
  imzML_annotations_path = labels_file,
  fwhm_path = fwhm_file,
  labelType = "rds",
  sample_id = "t3",
  FWHM_setUp = 400,
  minFreq = 0.01
)

3. Train XGBoost and compute SHAP values

sifs_compute_shap() trains the binary classifier and computes SHAP values for the VT pixels. The response passed to the function is the recoded y, so the function’s positive_class = 1 corresponds to tumor.

shap_results <- sifs_compute_shap(
  spmat_obj = obj$spData,
  labels = y,
  roi_name = "VT",
  train_ratio = 0.8,
  nrounds = 200L,
  positive_class = 1L,
  seed = 123L
)

4. Remove features with all-zero SHAP values

Most m/z features have no SHAP contribution. sifs_filter_features() removes features whose SHAP values are zero across all pixels.

filtered <- sifs_filter_features(
  shap_results = shap_results,
  focus_roi = "VT"
)

nrow(filtered$filtered_df)
#> [1] 416
filtered$removed_pct
#> [1] 95

The filtered data frame is used to choose the candidate m/z features for the spatial HMCS calculation. By default, the top 50 SHAP-ranked features are tested; this keeps the SPP/MPM/DSC step practical while preserving the strongest candidates.

5. Compute binary HMCS values

The spatial workflow uses sifs_compute_hmcs():

  1. searchAnalyte() builds an analyte point pattern for an m/z feature.
  2. probMap() estimates a spatially significant hotspot map.
  3. dsc() compares the hotspot window with the VT and non-VT windows.
  4. HMCS_VT = DSC_VT - DSC_nonVT.

The MPM analysis is seeded (seed = 123) and uses a fixed bandwidth (bw = 2.5) so the ranking is reproducible.

fwhm_obj <- readRDS(fwhm_file)

vt <- as.character(lbls$Vt_vs_all_lbls) == "0"
nonvt <- !vt

mz_top <- head(filtered$filtered_df$mzList, top_n_hmcs)

hmcs_df <- sifs_compute_hmcs(
  spData = obj$spData,
  mz = mz_top,
  fwhm_obj = fwhm_obj,
  vt = vt,
  nonvt = nonvt,
  spwin = obj$spwin,
  bw = 2.5,
  seed = 123,
  min_points = 100,
  verbose = FALSE
)

# Confirm the final binary HMCS with the package calculator.
hmcs_df$HMCS_VT <- HMCS_calculatorBinary(
  hmcs_df,
  focusROI = "VT",
  referenceROI = "nonVT"
)

hmcs_df <- hmcs_df[order(-hmcs_df$HMCS_VT), , drop = FALSE]

The HMCS bar plot shows the strongest positive spatial associations with VT. The SHAP bar plot shows the features with the largest mean absolute SHAP contribution. The two rankings answer related but different questions:

  • SHAP asks which features the classifier uses most strongly.
  • HMCS asks which features have hotspot maps that spatially resemble VT more than the non-VT reference.

7. Reproducibility notes

The example fixes the following settings:

  • sample_id = "t3"
  • FWHM_setUp = 400
  • minFreq = 0.01
  • seed = 123 for the train/test split and model
  • seed = 123 for probMap()
  • bw = 2.5 for the MPM bandwidth
  • top_n_hmcs = 50 for the HMCS candidate set

The FWHM binning step is required. On this dataset, FWHM binning alone leaves more than 500,000 features; minFreq = 0.01 reduces the axis to approximately 8,300 features, which is practical for XGBoost, treeshap, and the SPP/MPM/DSC loop.
