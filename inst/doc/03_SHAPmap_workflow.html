SHAPmap Visualization Workflow

Shad Arif Mohammed

2026-04-26

Introduction

This vignette demonstrates the complete workflow for generating SHAP (SHapley Additive exPlanations) value spatial heatmaps from mass spectrometry imaging (MSI) data. The workflow trains an XGBoost binary classifier, computes SHAP values using the treeshap package, and visualizes the results spatially on the MSI raster.

Prerequisites

The following R packages are required:

  • treeshap: For computing SHAP values from tree-based models
  • xgboost: For training the gradient boosting classifier
  • moleculaR: For MSI-specific functions (spatial window creation)
  • data.table: For efficient data manipulation
  • viridisLite: For color palettes
# Load required packages
library(treeshap)
library(xgboost)
library(moleculaR)
library(data.table)
library(viridisLite)

Step 1: Load Input Data

Overview

We load the MSI training data from the trainSet_spmat.rds file, which contains: - $spmat: Sparse intensity matrix (pixels × m/z features) - $coordinates: Pixel coordinates (x, y positions) - $mzAxis: m/z values for each feature column

Data Structure

The data is stored as a sparse matrix in dgCMatrix format for memory efficiency. Each row represents a pixel, and each column represents an m/z feature.

Step 3: Train XGBoost Classifier

Overview

Train an XGBoost gradient boosting classifier for binary classification. We use simplified parameters for faster computation while maintaining reasonable accuracy.

Step 4: Compute SHAP Values

Overview

Use the treeshap package to compute SHAP values. This requires:

  1. Unify the model using xgboost.unify()
  2. Compute SHAP values with treeshap()

The unified model format is required by treeshap to compute SHAP values efficiently. The SHAP values are stored in the $shaps component of the results.

cat("Computing SHAP values...\n")
#> Computing SHAP values...

# Step 4a: Unify the XGBoost model
# This converts the model to treeshap's required format
unified_model <- xgboost.unify(xgb_model, X_train)

# Step 4b: Compute SHAP values
# verbose = FALSE suppresses progress output
shap_results <- treeshap(unified_model, X_train, verbose = FALSE)

# Extract SHAP values from the $shaps component
shap_values <- shap_results$shaps

cat("SHAP values dimensions:", nrow(shap_values), "x", ncol(shap_values), "\n")
#> SHAP values dimensions: 3660 x 13144
cat("SHAP values class:", class(shap_values), "\n")
#> SHAP values class: data.frame

Step 5: Calculate Global SHAP Importance

Overview

Compute the mean absolute SHAP value for each feature to determine global importance. Rank features by importance to identify the top contributors to classification.

# Set feature names as m/z values
colnames(shap_values) <- as.character(mz_axis)

# Calculate mean absolute SHAP for each feature
mean_abs_shap <- colMeans(abs(shap_values))

# Create importance dataframe
global_shap_df <- data.frame(
  feature = names(mean_abs_shap),
  mean_abs_shap = as.numeric(mean_abs_shap)
)

# Sort by importance (descending)
global_shap_df <- global_shap_df[order(-global_shap_df$mean_abs_shap), ]

# Get top 10 features
top10_mz <- global_shap_df$feature[1:10]

cat("=== Top 10 m/z by Mean |SHAP| ===\n")
#> === Top 10 m/z by Mean |SHAP| ===
print(top10_mz)

Overview

Step 7: Generate Spatial SHAP Heatmaps

Overview

Create spatial heatmap visualizations (SHAPmaps) for each of the top 10 m/z features. This workflow:

  1. Creates a matrix matching the pixel coordinate system
  2. Maps SHAP values to spatial positions
  3. Applies a diverging color palette
  4. Overlays the tissue boundary

Understanding the Coordinate System

In R’s image() function: - Matrix rows correspond to y-axis (vertical direction) - Matrix columns correspond to x-axis (horizontal direction) - z[row, col] → image(x, y, z) where length(x) = ncol(z) and length(y) = nrow(z)

Matrix Construction

The matrix is constructed such that: - Rows correspond to y-coordinates (52 unique values: 138-189) - Columns correspond to x-coordinates (91 unique values: 788-878)

# Create output directory
shapmap_dir <- file.path(output_dir, "SHAPmaps")
dir.create(shapmap_dir, recursive = TRUE, showWarnings = FALSE)

# Get coordinate ranges
min_x <- min(coords$x)
min_y <- min(coords$y)
max_x <- max(coords$x)
max_y <- max(coords$y)

nx <- as.integer(max_x - min_x + 1)  # 91
ny <- as.integer(max_y - min_y + 1)  # 52

cat(sprintf("Raster dimensions: nx=%d, ny=%d\n", nx, ny))
#> Raster dimensions: nx=91, ny=52

# Create spatial window for boundary
spwin <- createSpatialWindow(pixelCoords = coords)

bdry <- spwin$bdry[[1]]

# Custom color palette: blue -> magenta -> red
pastelPalette <- colorRampPalette(c("#018bfb", "#027af4", "#ae12a5", "#cc0095", "#ff024f"))

# Colorbar helper function
add_colorbar <- function(col, breaks_vals, title) {
  usr <- par("usr")
  xpad <- (usr[2] - usr[1]) * 0.02
  xloc <- usr[2] + xpad
  yloc <- seq(usr[3], usr[4], length.out = length(col) + 1)
  rect(rep(xloc, length(col)), yloc[-length(yloc)],
       rep(xloc + xpad * 2, length(col)), yloc[-1],
       col = col, border = NA)
  axis(side = 4, at = yloc, labels = breaks_vals, las = 1, cex.axis = 0.7)
  mtext(side = 4, title, at = mean(yloc), line = 2.5, las = 0, cex = 0.8)
}

# Generate heatmaps for top 10 features
for (i in 1:10) {
  mz_val <- top10_mz[i]
  
  # Get SHAP values for this feature
  shap_vals <- local_shap_df[[as.character(mz_val)]]
  
  # Calculate quantile bounds for color scaling
  q05 <- quantile(shap_vals, 0.05)
  q95 <- quantile(shap_vals, 0.95)
  shap_range <- max(abs(q05), abs(q95))
  
  # Create matrix: rows = x (91), columns = y (52) to match image() expectations
  # image() expects: nrow(z) = length(y), ncol(z) = length(x)
  mat <- matrix(NA, nrow = nx, ncol = ny)
  
  for (j in 1:nrow(coords)) {
    xi <- coords$x[j] - min_x + 1
    yi <- coords$y[j] - min_y + 1
    if (xi >= 1 && xi <= nx && yi >= 1 && yi <= ny) {
      mat[xi, yi] <- shap_vals[j]
    }
  }
  
  # Define output file
  png_file <- file.path(shapmap_dir, sprintf("SHAPmap_%02d_mz_%.3f.svg", i, as.numeric(mz_val)))
  
  # Create plot
  svg(png_file, width = 12, height = 10)
  par(mar = c(4, 4, 3, 6), oma = c(0, 0, 2, 0))
  
  # Color settings
  ncol <- 100
  cols <- pastelPalette(ncol)
  breaks_vals <- seq(-shap_range, shap_range, length.out = ncol + 1)
  
  # Axis vectors
  x_axis <- seq(min_x, max_x, length.out = nx)
  y_axis <- seq(min_y, max_y, length.out = ny)
  
  # Create heatmap
  image(x = x_axis, y = y_axis, z = mat, col = cols,
        breaks = breaks_vals,
        xlab = "X (pixels)", ylab = "Y (pixels)",
        main = "", useRaster = TRUE)
  
  # Add tissue boundary
  lines(bdry$x, bdry$y, col = "black", lwd = 2.5)
  
# Add title
mtext(sprintf("m/z = %.3f (Rank #%d)", as.numeric(mz_val), i), side = 3, outer = TRUE,
        cex = 1.5, font = 2, line = 0)
  
  # Add colorbar
  add_colorbar(col = cols, breaks_vals = round(breaks_vals, 2), title = "SHAP")
  
  dev.off()
  
  cat(sprintf("Generated: %s\n", basename(png_file)))
}

Understanding the Output

SHAPmap Interpretation

Each SHAPmap shows the spatial distribution of SHAP values for a specific m/z feature:

  • Red colors (right side of palette): Positive SHAP values → feature pushes prediction toward class 1 (tumor)
  • Blue colors (left side of palette): Negative SHAP values → feature pushes prediction toward class 0 (normal)
  • Intensity: Magnitude of the SHAP value indicates feature importance at that pixel

Feature Selection

The top 10 features are ranked by mean |SHAP| across all pixels, representing the most important m/z values for classification overall.

Spatial Patterns

The heatmaps reveal: - Localized patterns: Where specific m/z features are important - Tissue heterogeneity: Spatial variation in feature relevance - Boundary effects: Feature importance near tissue edges
